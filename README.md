# 记账本

一个完全离线的本地记账应用。所有数据只保存在你自己的设备上，不联网、不上传、不需要注册。

应用主体是一个单文件网页（`index.html`），Android 版本通过 WebView 容器把它打包成 APK。同一份代码既能直接在浏览器里打开，也能装成手机 App。

## 功能

- **记一笔**：记录收入 / 支出，选择分类、金额与图标
- **快捷记账**：连点两下直接入账，长按可修改
- **本月概览**：本月总支出、结余、笔数一目了然
- **支出构成**：按分类看钱花在哪儿，支持按金额从高到低排序
- **备份与导出**：导出 JSON 完整备份（可在新手机上恢复）、导出 CSV 表格、导入账目

## 使用

### 网页版

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

### Android 版

下载 [`dist/ledger-2.4.apk`](dist/ledger-2.4.apk) 安装。若系统提示「未知来源」，需在设置中允许安装。

| 项目 | 值 |
| --- | --- |
| 应用名 | 记账本 |
| 包名 | `com.ink.ledger` |
| 版本 | 2.4 |

## 数据与隐私

账目数据保存在浏览器 / WebView 的 `localStorage` 中，不会发送到任何服务器。代码中不含任何外部 CDN、统计脚本或网络请求，断网状态下功能完全正常。

这意味着：

- 清除浏览器数据、卸载 App 会**一并清除账目**，请定期用「备份与导出 → 导出 JSON 备份」保存
- 换设备时，在新设备上用「导入账目」恢复 JSON 备份

## 项目结构

```
.

```

## 开发

没有构建步骤。修改 `index.html` 后刷新浏览器即可看到效果。

Android 包是 WebView 容器加载 `assets/index.html` 的产物，重新打包时需要用新的 `index.html` 替换容器内的 `assets/index.html` 后重新签名。
